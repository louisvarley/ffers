# LGPL-2.1 components and how to relink them

The game's synthesiser, which turns the original music into the `music.bin` pack, uses three
crates under the **GNU Lesser General Public License, version 2.1**:

| Crate | Version | What it is |
|---|---|---|
| `oxisynth` | 0.1.0 | The SoundFont synthesiser |
| `oxisynth-chorus` | 0.1.0 | Its chorus effect |
| `oxisynth-reverb` | 0.1.0 | Its reverb effect |

They are linked statically into `ffe-rs` and `ffe-launcher` (every build, on every platform).
Their copyright belongs to their authors; their licence text is in `THIRD_PARTY_LICENSES.txt`
in each download and in [THIRD_PARTY.md](THIRD_PARTY.md) (generated by
`python tools/third-party.py`). The rest of this project is MIT-licensed ([LICENSE](../LICENSE));
the LGPL covers only those three crates, not the game's own code.

## Your right to replace them

The LGPL lets you modify these libraries and use your modified copy in this program. To make that
possible, the complete source of the program is public, and the program is built entirely by Cargo
from pinned sources. To relink with your own copy:

1. Get the source of the release you have: the tag on
   <https://github.com/louisvarley/ffe-rs-classic> that matches the version in the file name
   (for example `v0.9.0`). Its `Cargo.lock` pins every dependency, the three crates included.
2. Get the crates' source: `cargo vendor` fetches it, or take it from
   <https://crates.io/crates/oxisynth> (and `oxisynth-chorus`, `oxisynth-reverb`), and make your
   changes.
3. Point the build at your copy by adding this to the workspace `Cargo.toml`:

   ```toml
   [patch.crates-io]
   oxisynth = { path = "../oxisynth" }
   oxisynth-chorus = { path = "../oxisynth-chorus" }
   oxisynth-reverb = { path = "../oxisynth-reverb" }
   ```

4. Build the programs again: `cargo build --release -p ffe-rs -p ffe-launcher`. (Leave out `--locked`:
   a patched dependency changes the lock file.) The result is in `target/release/`.
5. Packages are made from those programs by `tools/package.ps1` (Windows),
   `tools/package-appimage.sh` (Linux) and `tools/package-macos.sh` (macOS); see the README.

Nothing in the build or the game checks that the synthesiser is the original one.
