# GeneralUser GS

GeneralUser GS v2.0.3 by S. Christian Collins. The SoundFont is distributed
with the author's software-use license in `LICENSE`; preserve attribution and
license text with redistributions.

The project bundles the upstream 32,319,396-byte SF2 and uses it for launcher
first-run HMP synthesis through OxiSynth. The tracks are packed as mono PCM in
the launcher's ignored root `music.bin`. The game-specific HMP files are not
distributed.

Source: https://github.com/mrbumpy409/GeneralUser-GS
